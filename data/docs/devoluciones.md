# Returns

## Return window

The recipient has fourteen calendar days from delivery to start a return. After that window
the return is subject to the sender's policy and may be rejected. The delivery date recorded
on the order is what starts the window.

## How to start a return

A return is started from the customer area using the original order number. The system
generates a return label to stick on the parcel. The product must be in its original
packaging and in good condition; a used or damaged product may reduce the refund or cause the
return to be rejected.

## Drop-off or pickup

The return parcel can be dropped off at any convenience point in the network, or you can
request a home pickup in a morning or afternoon window. Home pickup for returns follows the
same time windows as delivery.

## Refund

Once the warehouse receives and validates the returned product, the refund is processed
within three to five business days to the same payment method. The original shipping cost is
only refunded if the return is due to a Nordport or sender error.
